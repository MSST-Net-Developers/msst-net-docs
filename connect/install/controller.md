## 控制器的作用

客户端控制器用于管理 **MSST-Net 客户端核心**。

其主要功能包括：

- 查看本机与核心的连接状态
- 创建、加入和退出房间
- 管理防火墙规则、权限组和访问记录
- 处理交互式授权请求
- 执行接入认证
- 修改设备名称与助记符
- 管理自定义域名
- 查看日志与诊断信息

控制器本身**不负责网络连接功能**，也不会自行做出任何网络或授权决定：它展示的所有状态都来自客户端核心。关闭控制器不会影响网络连接。

---

## 控制器类型

MSST-Net 3.1 的所有控制器共用同一套界面，按运行方式分为三种：

| 类型 | 平台 | 连接核心的方式 | 远程管理 |
|---|---|---|---|
| 桌面版 | Windows / Linux / macOS | 本机 IPC | 否 |
| 移动版 | Android | 内置核心 | 否 |
| WebUI 版 | 服务器 / 无桌面设备 | 本机 IPC，经 HTTPS 提供给浏览器 | 是 |

### 功能差异

| 功能 | 桌面版 | 移动版 | WebUI 版 |
|---|---|---|---|
| 规则向导与权限组管理 | 支持 | 不支持（可从授权请求、访问记录、房间成员添加规则） | 支持 |
| 为房间成员添加规则 | 支持（右键） | 支持（长按） | 支持 |
| 交互式授权 | 对话框 + 系统通知 | 对话框 + 带操作按钮的通知 | **不支持** |
| 访问密码与 IP 白名单 | — | — | 必需 |
| VPN 服务控制 | — | 支持 | — |
| 分应用代理 | — | 支持 | — |

## 界面导航

控制器包含以下页面：

| 页面 | 内容 |
|---|---|
| 首页 | 核心状态、接入认证、创建 / 加入房间、当前房间成员、本机标识与 ezPlay 主机名 |
| 防御 | 防火墙规则、Ping 开关、权限组管理、访问记录 |
| 域名 | 自定义 `.msst.net` 命名空间与 DNS 记录（需完成认证） |
| 设置 | 设备名与助记符、诊断与调试、高级网络选项 |
| 关于 | 版本与协议信息 |

## 桌面版

桌面版适用于具备桌面环境的设备（Windows / Linux / macOS），需要另外安装并运行客户端核心。

特点：

- 本地图形界面，支持系统托盘
- 交互式授权请求以系统通知提醒（Linux 使用原生桌面通知）

推荐给普通桌面用户使用。

---

## 移动版

移动版适用于 Android 设备。

特点：

- 原生移动端界面，适配手机等小屏幕
- **内置客户端核心**，无需单独安装核心组件
- 通过系统 VPN 服务接入，首页可以启动、休眠、恢复或停止 VPN 服务
- 支持"始终开启的 VPN"以及"屏蔽未使用 VPN 的连接"
- 支持**分应用代理**：在 **设置 → 分应用代理** 中选择不经过 MSST-Net 的应用
- 控制器界面未打开时，也会收到访问请求通知

> 从 3.0.x 升级时，设备身份保存在应用自己的数据目录中，升级后设备 ID 与虚拟 IP 保持不变。

---

## WebUI 版

WebUI 版适用于无桌面环境或需要远程管理的设备，通过浏览器访问。

详见：[《WebUI 远程管理》](/connect/install/webui)

## 连接客户端核心

桌面版与 WebUI 版通过本机 IPC 连接客户端核心：

| 平台 | 默认 IPC 路径 |
|---|---|
| Linux | `$XDG_RUNTIME_DIR/msst-net/ipc.sock`，其次 `/run/msst-net/ipc.sock` |
| macOS | `$TMPDIR/msst-net/ipc.sock`，其次 `/var/run/msst-net/ipc.sock` |
| Windows | `\\.\pipe\msst-net-ipc` |

可以通过环境变量 `MSST_IPC_PATH` 指定其他路径。

### 访问权限（Linux / macOS）

客户端核心是特权进程，因此并不是能打开 IPC 套接字就能操作核心。核心会检查连接方的系统用户，并授予以下角色之一：

| 角色 | 授予对象 | 权限 |
|---|---|---|
| 管理（admin） | 运行核心的用户、root、通过 `sudo` 启动核心的用户、本地用户组 `msst-net` 的成员 | 全部操作 |
| 只读（viewer） | 其他拥有本地登录会话的用户 | 只能查看状态 |
| — | 其他用户 | 拒绝连接 |

当核心以 root 身份作为系统服务运行时，请将日常使用的账号加入 `msst-net` 用户组，以获得管理权限：

```bash
sudo groupadd -f msst-net
sudo usermod -aG msst-net $USER
```

用户组成员资格在每次连接时检查，**无需重启核心**；但需要重新登录系统，新的组成员身份才会对该用户的进程生效。

以只读角色连接时，控制器会显示只读提示，修改操作不可用。

### 版本兼容

控制器会在连接时与核心协商 IPC 协议版本，并在 **关于** 页面显示双方的协议版本。核心版本较旧、缺少某些功能时，控制器会禁用对应功能并说明原因。

## 如何选择控制器

普通桌面用户：

建议使用 **桌面版**。

服务器用户：

建议使用 **WebUI 版**。

移动端用户：

建议使用 **移动版**。
