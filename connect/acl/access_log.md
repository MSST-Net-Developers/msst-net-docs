## 什么是访问记录

**访问记录**保存了最近其他设备访问本机时，防火墙做出的每一次判定。

通过访问记录，可以了解：

- 哪台设备在什么时间尝试访问了本机的哪个服务或端口
- 这次访问是被允许、拒绝还是静默拒绝
- 做出判定的原因（命中了哪条规则，或者为何没有弹出授权）

访问记录可以在控制器的 **防御 → 访问记录** 中查看。

---

## 记录内容

每条访问记录包含：

| 字段 | 说明 |
|---|---|
| 来源设备 | 发起访问的设备（显示设备名，未知时显示设备 ID） |
| 时间 | 访问发生的时间 |
| 目标 | 访问的服务名（若为已知服务）或协议/端口 |
| 判定结果 | 允许、拒绝或静默拒绝 |
| 判定原因 | 见下表 |

### 判定原因

| 原因 | 说明 |
|---|---|
| 规则 | 命中了某条防火墙规则（显示规则备注，没有备注时显示规则 ID 前 8 位） |
| 交互式授权 | 无规则匹配，已向用户发出授权请求 |
| 交互式授权超时 | 授权请求在 60 秒内未得到处理 |
| 待处理的访问请求过多（未弹出提示） | 同一来源或全局待处理请求已达上限，未再弹出提示 |
| 无匹配规则（默认拒绝） | 无规则匹配，且该来源不满足触发交互式授权的条件 |

---

## 合并与容量

- 30 秒内来自同一设备、访问同一目标且判定相同的多次访问，会合并为一条记录，并显示次数（如 `×12`）
- 访问记录最多保留最近 **500** 条，超出后最早的记录会被移除
- 访问记录保存在客户端核心的内存中，核心重启后清空
- 可以点击 **清空** 手动清除全部记录

---

## 从访问记录调整规则

每条访问记录下方提供快捷操作，可以直接为该来源设备、该协议/端口创建一条设备级规则：

| 记录状态 | 可用操作 |
|---|---|
| 被拒绝或静默拒绝 | **允许一次**（10 分钟后失效）、**始终允许**、**始终拒绝** |
| 被允许，但并非由永久允许规则放行 | **始终允许** |
| 由永久允许规则放行 | **撤销授权**（删除该条规则，并立即切断它放行的已建立连接） |

移动端无法手动创建规则，访问记录是在移动端添加规则的主要入口之一。
